Optional — only needed for restricted items.
Public collections need no keys. For restricted items, the surest route is to be logged in to archive.org in this browser (downloads use your session). Keys here are exported to credentials.json for the app; grab yours from your S3 login page at archive.org/account/s3.php.

GitHub access token

Optional — lifts the update-check rate limit. GitHub allows only ~60 checks/hour per IP without a token, which shows as “latest release: rate-limited — try again later” on the Emulators and Apps tabs. A classic token with no scopes (public read only) is enough. Create one at github.com/settings/tokens. Stored only on this PC and sent only to api.github.com.

Device Transfer

Both devices on the same network. On the Switch, open the matching receive screen — it shows IP:PORT/CODE to type below. The IP and port are remembered; the code changes each time the receive screen opens.
Pushes the collection you're editing on the Archive Collections tab to the console. On the Switch, open Settings › PC Sync › Import collection — it shows the address to type above — then hit Send. Leave that screen open: it stops listening once the file arrives, and you confirm the import there.
Loads the collection the console is currently running into the Archive Collections editor, so you can edit it and send it back. Open the same Import collection screen on the Switch for the address, then hit Get from Switch.
Pushes a game file into a console's installed folder — handy for a ROM you already have on your PC. On the Switch, open the Installed tab, highlight the console, press Y for its ROM folder, and choose Receive from PC — it shows the address to type above. It goes into whichever console you opened that screen from, so pick the right one there; then hit Send and confirm on the Switch if it would replace a file already there.
Pushes a freshly built HaulNX .nro to the console — no USB cable needed, and the same version as installed is fine. A zipped/RAR'd/7z'd build works too — the Switch unpacks it before installing. On the Switch, open Settings › Updates › Update app over Wi‑Fi; you confirm the install there and restart to switch to the new build.
